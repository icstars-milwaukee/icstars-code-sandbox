The Build Step

JSX is not JavaScript. No browser has ever understood it. Something has to translate it first — and that something is why a React project needs npm install, a package.json and Vite. Watch the translation happen, then install one yourself.

1 · Watch the translation

Left is what you write. Right is what actually runs. Edit the left and the right keeps up. This is the entire job of the build step — there is no magic under it. 


      

    


    

      
      
    


    


    
    2 · What npm install is for

    

      A React project is four files doing four jobs, plus a folder you never open.
      Nothing here is ceremony.
    


    

      
        
The thingIts one job

      
      
        

          package.json
          The shopping list. Names every package your project needs, and the
          commands you can run. It is checked into Git; it is small; you read it.
        

        

          package-lock.json
          The receipt. The exact version of every package, including the
          packages your packages wanted. Checked in so your laptop and CodeSandbox install
          the identical thing. You never edit it by hand.
        

        

          node_modules/
          The groceries. The actual downloaded code — thousands of
          files, tens of megabytes. Never checked into Git, because
          npm install recreates it from the two files above.
        

        

          vite.config.js
          The kitchen. Tells Vite to expect React, so it knows to run
          that JSX translation on every file as you save it.
        

        

          dependencies
devDependencies		
          Ships vs. builds. react is a dependency — it
          runs in the user's browser. vite is a devDependency — it builds
          the thing and is never sent to anyone. Getting this backwards ships a toolchain
          to your users.
