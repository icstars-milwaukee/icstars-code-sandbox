An API is a URL that gives you data instead of a page

Four words

API
A computer that hands out data when you ask. Tonight: pokeapi.co
Endpoint
One specific URL on it. /pokemon/25 gives one, /pokemon?limit=151 gives a list
JSON
How data is written down while it travels. Looks like JavaScript, because it is
Status code
200 worked · 404 no such thing · 500 their fault

REST, HTTP verbs, headers, auth tokens, rate limits — all of it can wait. People quit this subject because somebody handed them forty words on night one.

Reading JSON · one question answers half of tonight's bugs

Braces or brackets?

CURLY BRACES = one thing. /pokemon/25 gives you: { "id": 25, "name": "pikachu", "weight": 60, "sprites": { "front_default": "https://.../25.png" } } ↑ NESTED. A dot means "go inside": pokemon.sprites.front_default SQUARE BRACKETS = a list. /pokemon?limit=151 gives you: { "results": [ { "name": "bulbasaur", "url": ".../pokemon/1/" }, { "name": "ivysaur", "url": ".../pokemon/2/" }, ...149 more ] }

Brackets mean you can loop it, count it, and pick from it at random. That one sentence is why a game is possible tonight.

Three passes, three rules

I do → We do → You do

  • 1During I do, hands off keyboards. Typing along means debugging instead of watching
  • 2Read the red text. F12 → Console. An error is the computer telling you what's wrong — information, never a verdict on you
  • 3Say STUCK the moment you're stuck. Stuck is a group problem here, never a private one

js/step-2.js. New URL — a LIST this time. YOU TYPE: const response = await fetch("https://pokeapi.co/api/v2/pokemon?limit=151"); const data = await response.json(); allPokemon = data.results; // 151 of them, in [ ] Pick one nobody chose — that's a mystery: mystery = allPokemon[Math.floor(Math.random() * allPokemon.length)]; Build the picture address from its number, then hide it: const id = mystery.url.split("/")[6]; // ".../pokemon/25/" → "25" sprite.src = SPRITE_BASE + id + ".png"; sprite.classList.add("hidden"); // CSS: filter: brightness(0)
