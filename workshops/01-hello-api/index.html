Hello, API

30 minutes · one game, three passes. Build "Who's That Pokémon?" out of data you never typed.

Start here
Live editor The playground → All six projects in a tree, already running. Click a folder to run it, click a file to open it, then break it on purpose. Nothing to install. Instructor The workshop deck → 16 slides with three live demos built in. Arrow keys to drive. Ctrl+P saves it as a PDF.

The projects

Six folders. Each one is an index.html and a js/main.js, and each one opens and runs on its own — no server, no build step, nothing installed. Open them from the playground, or just double-click the file.

I do 1 — One Pokémon The three lines: ask, unwrap, show. Name, weight, type, and its picture on the page. We do 2 — The mystery silhouette A list of 151, a random pick, and one line of CSS that hides it. You do 3 — Make it a game Three TODOs: four guess buttons and a score. It runs with all three unfinished and tells you which one to go do. (answer key) Homework 4 — Another API Same three lines, somebody else's data. If it works against an API you have never seen, you didn't memorise this — you learned it. (answer key)

The source tree

Every js/main.js ends with a short BREAK IT ON PURPOSE list — a few things to change, and what each one teaches when it goes wrong. That list is the point of the playground.
