Molson Data

Write a SELECT, send it to the Cycle 21 gateway, put the rows on the page. Three functions do the whole job — and one of them is wrong.

Your team's data

The gateway is read-only: your SQL has to start with SELECT or WITH, and it will tell you off if it doesn't. It speaks PostgreSQL. The query below is the one to run first — it asks the database what tables exist, because you cannot query data you cannot name. Then swap in a real table.

Once that gives you a name, look at the thing itself: SELECT * FROM <schema>.<table> LIMIT 20. Then start asking it questions — COUNT(*), GROUP BY, ORDER BY.
