Code Sandbox

A library of guided tech learning workshops. Every one of them runs in a browser, ends in something that works, and stays here after the session is over.

Nothing in here is a lecture. Each workshop is a deck you can present, a set of files you can run, and a finished build to compare yours against. No servers, no npm, no accounts — a browser and VS Code. Walk out with the thing built.

The shelf

 

How every workshop is built

Same three passes at the same artifact, every time. People quit this subject when night one is forty new words and a blank file. They don't quit when they watched it work first.

Pass 1

I do

Hands off keyboards. Typing along means debugging instead of watching. The instructor builds the smallest version that works.

Pass 2

We do

Keyboards up, nobody types ahead. A checkpoint after every step — “you should see this. Thumbs up.”

Pass 3

You do

Three TODOs in a file that already runs. An answer key exists, and looking at it is allowed. Saying STUCK out loud is encouraged.

Add the next workshop

Fifteen minutes of setup, then you're writing content. The template is a working workshop with the words taken out — it opens and runs before you change a thing.

  1. Copy workshops/_template/ to workshops/0N-your-slug/. Numbers are shelf order, not week order.
  2. Rewrite REF-deck.html. Arrow keys drive it, Ctrl+P saves it as a PDF. Do not touch the <style> block — the palette is the house palette.
  3. Fill in the three step pages and their files in js/. Leave exactly three TODOs in the You do step.
  4. Write the answer key. If you can't finish your own TODOs in nine minutes, they're too big.
  5. Add one object to js/workshops.js. The card builds itself.
  6. Teach it to real people, then change status to "ready". That word means survived a cohort, not finished writing.

Full checklist in CONTRIBUTING.md, including the parts of the house style that are not up for redesign.

The source tree

Plain static site. Pages are HTML, styles are CSS, scripts are JS, and the whole thing is served straight off GitHub Pages. There is no build step to break.
